## Fidélité — anciens clients suivis sur papier

Pour reprendre un client déjà suivi sur papier :
1. Ouvrir **Clients & véhicules**.
2. Créer le client s'il n'existe pas encore.
3. Dans **Historique existant (facultatif)**, saisir **Visites déjà effectuées** et **Points déjà acquis**.
4. Enregistrer.
5. Lors des prochaines ventes, rechercher le client par son nom dans **Nouvelle vente** : son historique de fidélité sera repris automatiquement.

Les valeurs saisies sont un point de départ historique ; les nouvelles ventes continuent ensuite d'incrémenter les visites et points selon la configuration du programme.

## Filtre des ventes par période

Dans **Ventes & commandes**, le filtre de période propose :
- **Aujourd'hui**
- **Hier**
- **Hebdomadaire** (lundi à aujourd'hui)
- **Mensuel** (1er du mois à aujourd'hui)
- **Périodique ou personnalisé** (choix d'une date de début et d'une date de fin)
- **Toutes les périodes**
